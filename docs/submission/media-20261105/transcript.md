## Inspect the evidence behind a measurement

A measurable cup to disc ratio can still come from the wrong structure. HyunOptic joins two model outputs, unresolved decisions, and evidence export in one local research session. This demonstration uses synthetic images and two small models trained on the CPU. These are actual application captures, with edited timing and synthetic narration.

## Create a local review session

The public preparation command has already trained both models for eighty epochs. Seed forty three is the primary model; seed forty two is the comparison. I import four synthetic images and one deliberately unreadable file through the real file chooser. Local retention is confirmed before I create the session.

## Preserve completed work and failed inputs

Processing runs in a bounded step and saves each completed input. The result is four completed images, eight predictions, and one retained input error. Unreadable data receives a terminal explanation, without a retry that cannot repair the file.

## Compare source and identified model outputs

The source and both model overlays share the same image coordinates. Model identities remain attached to their outputs. The boundaries and predicted ratios differ; disagreement is not a calibrated confidence score. Both models can agree and still be wrong.

## Keep an unresolved decision and resume

I mark the first case held and choose the reason uncertain. Save and next stores that decision, then opens the next unreviewed case in the current order. After a full browser reload, reopening the original case restores held and uncertain. Keyboard Tab navigation reaches the review controls, and Enter saves without a mouse.

## Download and independently verify evidence

I build the evidence package and download that verified ZIP. A separate checker accepts its six payloads and confirms the held decision. Original images, masks, filenames, paths, and private notes are excluded. Hashes establish consistency, not anonymity or scientific truth.

The repository provides a synthetic setup, reproducible checks, and research evidence with explicit limits. All changes shown were prepared before the hackathon; later event work must be disclosed separately. HyunOptic is research software, not a diagnostic or patient care tool.
