# Rubric-to-evidence map

Based on the [official public rubric](https://global-ai-builders-challenge.devpost.com/resources), checked 2026-11-04. This map supplies evidence; it does not assign a predicted score or guarantee that judges award a checkpoint.

| Area | Concrete evidence available | Limit / final action |
| --- | --- | --- |
| Problem value and practicality (20) | Defined ophthalmic research review task; actual full-source/model comparison; persistent decisions and export instead of disconnected files/notes | Feature comparison only; no participant study, measured efficiency or clinical benefit |
| AI integration and development (30) | Real image-only PyTorch inference; two verified frozen models; CPU synthetic preparation; explicit model/input/AI disclosures; observed failing regressions before fixes | Disagreement is not confidence; private research weights are not redistributed; person-specific A4 checking remains pending |
| Functionality and reliability (30) | Browser workflow and separate ZIP verification; ordinary/repeat/interrupted/changed-bundle checks; 326 local tests; CI evidence manifests | Controlled interruption is not an OS crash; repeat images are not patients; latest remote CI must match final submitted version |
| Design and user experience (20) | Full context and overlays; visible counts/errors; recognizable model names; actual 30 MB upload limit; held reasons; refresh/conflict behavior | Local draft is edited stills; final actual-use video and human usability review still needed; no formal accessibility certification |

The [execution report](../experiments/2026-11-04-submission-readiness/README.md) links expected/observed values and actual captures. The [description draft](DEVPOST_DRAFT.md) provides comparison, AI decisions and research limitations. The video should demonstrate the task; detailed supporting evidence belongs in the description. Hosting and outside feedback are optional under the current rubric, but the required public video, source access, disclosures and roster are not optional.
