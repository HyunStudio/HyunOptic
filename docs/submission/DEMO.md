# Three-minute demonstration script

Record the actual final application. Use synthetic images/models unless you have verified public display rights. Label synthetic fixtures and any time-compressed or precomputed steps throughout. A written script is not an uploaded video.

| Time | Actual action / message |
| --- | --- |
| 0:00–0:25 | Explain the research problem: a model can output a measurement on the wrong structure. State research-only scope and the demo's synthetic status. |
| 0:25–0:55 | Select two verified local bundles, import images, confirm local copying and process a bounded step. Show model identities and processing counts. |
| 0:55–1:40 | Open the priority list, inspect the full source and two overlays. Explain disagreement is not error probability; agreement can also be wrong. |
| 1:40–2:10 | Save a held decision with reason; rerun/reopen the session and show the persisted record. |
| 2:10–2:35 | Build and download ZIP; run its independent verifier. Explain private images/names/notes are excluded. |
| 2:35–3:00 | Show a failed input or interrupted step without losing completed records. State actual test results and unvalidated ranking efficiency. |

Put detailed experiment sources, baseline/event contributions, AI disclosure, setup requirements and evaluation limitations in the project description. Never substitute a mock screenshot for real execution. A public video URL and personal final review still need to be supplied before submitting.
